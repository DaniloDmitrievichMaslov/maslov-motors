# INSTRUÇÕES PARA TRANSFERIR PARA WORD

## Passo a Passo

### 1. Copiar o Conteúdo
1. Abre o ficheiro `RELATORIO_PAP_MASLOV_MOTORS.md`
2. Seleciona **TODO** o texto (Ctrl+A)
3. Copia (Ctrl+C)

### 2. Colar no Word
1. Abre o Microsoft Word
2. Cria um novo documento em branco
3. Cola o texto (Ctrl+V)
4. **OU** usa "Colar Especial" > "Texto não formatado" para controlo total

### 3. Aplicar Formatação

#### Configuração de Página
1. **Layout** > **Margens** > **Margens Personalizadas**
   - Superior: 2,5 cm
   - Inferior: 2,5 cm
   - Esquerda: 3 cm
   - Direita: 2,5 cm

#### Tipo de Letra
1. Seleciona todo o texto (Ctrl+A)
2. **Base** > **Tipo de Letra** > **Verdana**

#### Tamanhos de Letra
1. **Títulos principais (I, II, III...):**
   - Seleciona o título
   - Tamanho: **14**
   - **Negrito**

2. **Subtítulos (1.1, 2.1, 3.1...):**
   - Seleciona o subtítulo
   - Tamanho: **12**
   - **Negrito**

3. **Texto normal:**
   - Seleciona o texto
   - Tamanho: **10**

#### Alinhamento e Espaçamento
1. Seleciona todo o texto (Ctrl+A)
2. **Base** > **Parágrafo** (clica na setinha)
3. Configurar:
   - **Alinhamento:** Justificado
   - **Espaçamento entre linhas:** 1,5 linhas
   - **Avanço Especial:** Primeira linha: 1,25 cm

#### Início de Capítulo
Para cada capítulo principal (I, II, III...):
1. Coloca o cursor antes do título
2. **Inserir** > **Quebra de Página** (Ctrl+Enter)
3. Seleciona o título
4. **Parágrafo** > **Espaçamento Antes:** 134,75 pt

### 4. Criar Estilos (Opcional mas Recomendado)

Para não repetir a formatação manualmente:

1. **Criar Estilo "Título Capítulo":**
   - Formata um título como queres
   - Seleciona-o
   - **Base** > **Estilos** > **Criar um Estilo**
   - Nome: "Título Capítulo"

2. **Criar Estilo "Subtítulo":**
   - Mesmo processo para subtítulos

3. **Aplicar Estilos:**
   - Seleciona o texto
   - Clica no estilo criado

### 5. Verificar Numeração

- **Capítulos principais:** I, II, III, IV, V, VI, VII, VIII, IX, X
- **Secções:** 1.1, 1.2, 2.1, 2.2, etc.
- **Sub-secções:** 1.1.1, 1.1.2, etc.

### 6. Índice Automático (Opcional)

1. Aplica estilos "Título 1" aos capítulos
2. Aplica estilos "Título 2" às secções
3. **Referências** > **Índice** > **Índice Automático**

### 7. Guardar

1. **Ficheiro** > **Guardar Como**
2. Formato: **Documento do Word (.docx)**
3. Nome: `RELATORIO_PAP_MASLOV_MOTORS.docx`

## Problemas Comuns

**O texto ficou com formatação estranha:**
- Cola como "Texto não formatado" e formata manualmente

**Os símbolos Markdown (#, *, etc.) aparecem:**
- Remove-os manualmente ou usa Localizar/Substituir

**As tabelas não ficaram bem:**
- Recria as tabelas no Word: **Inserir** > **Tabela**
