## Tema

Desenvolvimento de uma aplicação web para gestão de oficina automóvel.

---

## Título Provisório do Projeto

**Maslov Motors — Sistema de Gestão para Oficina Automóvel**

---

## Fundamentação

Atualmente, muitas oficinas automóveis ainda recorrem a métodos manuais e registos em papel para gerir os seus clientes, veículos e serviços. Esta abordagem leva à perda de informação, dificulta o acompanhamento do histórico de serviços e torna a gestão ineficiente.

Existe uma necessidade real de digitalizar estes processos, oferecendo tanto aos clientes como aos proprietários de oficinas uma plataforma moderna, segura e acessível a partir de qualquer dispositivo com acesso à internet.

O projeto Maslov Motors pretende responder a esta necessidade, criando uma aplicação web que centraliza toda a gestão da oficina numa única plataforma, com funcionalidades para clientes e administradores.

---

## Objetivo Geral

Desenvolver uma aplicação web completa e funcional para a gestão de uma oficina automóvel, que permita digitalizar e modernizar os processos de registo de clientes, veículos e serviços, oferecendo uma interface moderna e segura.

---

## Objetivos Específicos

1. Implementar um sistema de autenticação seguro com registo e login de utilizadores.
2. Criar uma área de cliente para registo de veículos, consulta de histórico de serviços e pedidos de orçamento.
3. Criar uma área de administrador para gestão completa de clientes, veículos e serviços, com cálculo automático de margens e lucros.
4. Integrar um chatbot com inteligência artificial para assistência aos clientes.
5. Desenvolver um dashboard com estatísticas e gráficos para o administrador.
6. Implementar um sistema de relatórios.
7. Garantir a segurança dos dados com políticas de Row Level Security (RLS) em todas as tabelas da base de dados.
8. Criar uma interface responsiva e moderna que funcione em qualquer dispositivo (desktop, tablet, telemóvel).
